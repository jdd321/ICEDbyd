# ICED byd website

A responsive, static website for ICED byd, built with plain HTML and CSS. It features café photos, menu highlights, the hangout space, and visit details drawn from the supplied promotional images.

## Preview

Open `index.html` in a browser. Images are stored in `assets/` and use relative paths, so the site works locally and can be hosted as a static website.

## Notes

Menu prices, hours, contact information, and location are transcribed from promotional images and may change. Confirm current details with ICED byd before visiting or ordering.

## Photos

The `assets/` folder contains the café photos supplied for this website.
